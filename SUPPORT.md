# Support

For Denny Agent Workflows, open an issue in this repository or email info@afteam.tech. Include the skill name, the host product, the unexpected behavior and a minimal reproduction with fictional or redacted data.

Do not include passwords, API or license keys, private session exports or unrelated repository contents. For native Denny Agents installation and licensing questions, use [AFTEAM support](https://t.me/AFTeamStore_bot).

The package prepares documents. It cannot confirm that an Office assignment was submitted, operate a Mac notch, start another agent or publish a code change. Report those as separate integration requirements rather than assuming the package performed them.
