# Privacy — Denny Agent Workflows

Effective date: 4 November 2026. Publisher: AFTEAM. Contact: info@afteam.tech.

This notice covers this skills-only package, not the native Denny applications or separately connected services.

## Inputs and processing

The package contains Markdown instructions, templates, manifests and visual assets. It has no server, MCP connection, executable scripts, analytics or telemetry. It does not independently collect or transmit conversation text, repository files, identifiers, IP addresses, usage events or credentials to AFTEAM.

When a skill is invoked, the host assistant processes the request and the files or other context the user authorizes it to inspect. Typical inputs are project requirements, code changes and test reports. Typical outputs are assignment briefs, handoff documents and reviews. Processing by Claude, Codex and their associated services is governed by the host provider's terms, privacy policy and account settings.

## Retention and recipients

AFTEAM receives no routine skill inputs or outputs and maintains no plugin-side dataset or retention period for them. Outputs left in a chat follow the host's retention settings. Files a user chooses to save remain in their chosen workspace until they delete them. This package does not establish additional recipients or storage locations.

Repository hosting and package downloads are handled by GitHub or the host plugin directory under their respective policies. If a user independently sends support material to AFTEAM, it is received in the chosen support channel; it is not an automated plugin upload. Avoid including credentials or unrelated private data in support messages.

## Controls

Users can choose which inputs to provide, decline file access, remove generated files and disable or uninstall the plugin through the host application. Uninstalling the plugin does not itself delete chat history or user-saved documents. Questions about this package's data practices can be sent to info@afteam.tech.
